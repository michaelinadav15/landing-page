# תיקיית נכסים ותמונות - השקעות בלי חליפות

מבנה התיקיות בפועל:

- `hero/nadav-bordeaux.jpg` - התמונה הראשית של נדב בהירו (חולצה בורדו)
- `logo/buffett-pajama-logo.png` - לוגו וורן באפט בפיג'מה, מוצג דהוי ברקע ההירו
- `nadav/` - תמונות נוספות של נדב (בצבא, בישיבה) לסקשן "מי אני"
- `lectures/lecture-01.jpg` עד `lecture-12.jpg` - תמונות מהרצאות בצבא, בסליידר הנע אוטומטית מתחת להירו
- `quotes/buffett.png`, `gates.png`, `kiyosaki.png` - תמונות לכרטיסי הציטוטים בסקשן "מה המטרה האמיתית"
- `feedback/feedback-01` עד `feedback-12` - צילומי מסך של פידבקים מלקוחות (וואטסאפ/אינסטגרם)
- `portfolios/portfolio-01.jpg` עד `portfolio-09.jpg` - צילומי מסך של תיקי השקעות אמיתיים של בוגרים

כדי להחליף/להוסיף תמונה: שומרים קובץ בתיקייה המתאימה ומעדכנים את הנתיב ב-`index.html`.
